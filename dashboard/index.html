Which protocol launches next — and what would its token be worth?

Every protocol below records no token in the snapshot. The radar prices each one the way the market already prices live tokens, ranks them by that implied value, and gives a farm plan for each. An implied value is this radar’s claim, never make.fun’s, and it says nothing about whether or when a token is issued.

How the value is worked out

Implied value = TVL × category multiple × growth × maturity. The category multiple is the median market-cap-to-TVL ratio of the live-token protocols in the same category (at least three of them), or the median across every live token when the category has too few to price against. Growth is the protocol’s seven-day TVL change, clamped to −50%…+100% and weighted 0.6. Maturity rewards how long a protocol has run with no token, with diminishing returns (square root over four years; an unknown listing date counts as one year). No protocol name is ever special-cased: the same formula scores every row.

A protocol is shown as pre-token when its DefiLlama record carries no token. The record is not proof it has none. Wrapped, staked and bridged products of tokens that already trade, exchanges and versioned pools are set aside, and live-token protocols are shown separately with the market’s own capitalisation, never mixed into the ranking.
